# Apache Ignite (apache-ignite)
Apache Ignite is a distributed database for high-performance computing with in-memory speed. It provides SQL, key-value, compute, and machine learning APIs with support for ACID transactions across distributed caches.

## APIs

### Apache Ignite REST API
Ignite provides a REST API for cache operations and cluster management, SQL API with JDBC/ODBC drivers, Key-Value API, Compute API for distributed processing, Service Grid API, and thin client APIs for Java, .NET, C++, and Python.
